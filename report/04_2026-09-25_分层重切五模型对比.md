# 分层重切综合对比报告（极耳翻折/撕裂 | 验证集 val_strat 89 张全图）

## 与旧报告的核心差异

- 旧 `compare_report.md` 用 train.txt(192)/val.txt(88)：train 负样本 1.6% vs val 46.6% 严重失配，且排除 ~163 张负样本。
- 本报告用 `split_stratified.py` 对全部 446 张按类别组合分层 8:2：**train/val 负样本比例 47.1% / 47.2% 已对齐**，全部负样本纳入。
- 五模型均在同一新划分上**从零重训**（patience=100 早停，每 epoch 评估存 best），同一 val_full GT、同一语义 IoU 口径。

## v2-fast 加速说明

- v2(+TTA) -> v2-fast: 推理 4005ms -> 842ms, 约 4.8x 提速
- 代价: mIoU 0.7684 -> 0.7531, silie IoU 0.5983 -> 0.5611 (TTA 对 silie 贡献大, 去掉后 silie 回落)

## v2 vs v1 提升分析（v2 带 TTA）

- mIoU: 0.7313 -> 0.7684
- silie IoU: 0.5300 -> 0.5983
- fanzhe IoU: 0.6750 -> 0.7162

## 说明

- v1/v2 同骨干(MiT-B1)。v2 差异: 损失(CE->Focal+Dice+Lovasz)、分辨率(512->640)、Copy-paste silie、断点续训。
- v2-fast 与 v2 同模型同权重, 仅推理不同: 批量(bs16)+FP16+stride448+无TTA。
- 全部模型预测转语义图后算同一套 per-class IoU/mIoU, 公平口径。
- 本轮为分层重切后从零重训; 与旧 `compare_report.md`(失配划分) 不可直接比绝对值, 只可比"分层是否拉平失配后各模型相对位次"。
- val_strat 含 42 张负样本(47.2%); background IoU 仍会偏高, 缺陷类(silie/fanzhe)IoU 为选型核心。
