# SegFormer v2 改进对比报告（极耳翻折/撕裂 | 验证集 val.txt 88 张全图）

## v2 改进点: Focal+Dice+Lovasz 损失 | 640 分辨率 | Copy-paste silie | 断点续训

## 像素级指标（同口径，全图对比）

| 指标 | v1 (b1, CE) | **v2 (改进, +TTA)** | **v2-fast (无TTA, 加速)** | YOLOv8n-seg | Mask2Former |
|---|---|---|---|---|---|
| mIoU | 0.6137 | 0.6839 | 0.6184 | 0.6055 | 0.6176 |
| background IoU | 0.9827 | 0.9857 | 0.9849 | 0.9887 | 0.9825 |

## 推理速度（RTX 3090，全图 ~3000x2600）

| 模型 | 平均推理 ms/图 | TTA | 加速手段 |
|---|---|---|---|
| SegFormer v1 | 654 | 否 | bs1 fp32 stride448 |
| SegFormer v2 | 3836 | 是 | bs1 fp32 stride320 (慢) |
| **SegFormer v2-fast** | 804 | 否 | **bs16 fp16 stride448** |
| YOLOv8n-seg | 74 | 否 | imgsz=1200 单次 |
| Mask2Former | 3288 | 否 | 滑窗实例 |

## v2-fast 加速说明

- v2(带TTA) -> v2-fast: 推理 3836ms -> 804ms, 约 4.8x 提速
- 代价: mIoU 0.6839 -> 0.6184, silie IoU 0.4951 -> 0.3128 (TTA 对 silie 贡献大, 去掉后 silie 回落)
- v2-fast 仍略胜 v1: mIoU 0.6184 vs 0.6137, 推理速度接近 v1

## v2 vs v1 提升分析（v2 带 TTA）

- mIoU: 0.6137 -> 0.6839
- silie IoU: 0.3357 -> 0.4951 (改进主要目标)
- fanzhe IoU: 0.5228 -> 0.5710

## 说明

- v1/v2 同骨干(MiT-B1)。v2 差异: 损失(CE->Focal+Dice+Lovasz)、分辨率(512->640)、Copy-paste silie、断点续训。
- v2-fast 与 v2 同模型同权重, 仅推理不同: 批量(bs16)+FP16+stride448+无TTA。
- 全部模型预测转语义图后算同一套 per-class IoU/mIoU, 公平口径。
- 选型建议: 要精度用 v2(+TTA, 0.684/3836ms); 要速度用 v2-fast(0.618/804ms) 或 YOLO(0.606/74ms)。
