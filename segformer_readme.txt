 ● 厉飞雨                                                                                                                                                                       
                                                                                                                                                                                
   结论先说：两边的模型结构完全一样——都是 SegformerForSemanticSegmentation（MiT-B1 骨干 + 轻量 MLP 解码头），且都从同一个本地权重 segformer_baseline/models/segformer-b1-ade 初
   始化（v2 的 config 里明确写了"复用已转好的 b1 权重"）。区别全部在训练策略和推理流程上，v2 是在 baseline 基础上做的改进版。

   具体差异对比如下：                                                                                                                                                           
                                                                                                                                                                                
   ┌────────────────┬────────────────────────────────────────────────────────────────┬──────────────────────────────────────────────────────────────────────────────────┐       
   │ 维度           │ segformer_baseline                                             │ segformer_v2                                                                     │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 模型结构       │ MiT-B1 + MLP head                                              │ 相同，未改架构                                                                   │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 滑窗切块       │ 512×512，stride 384                                            │ 640×640，stride 512（保 silie 细节）                                             │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 损失函数       │ 加权交叉熵（class_weights=[0.20, 2.00, 1.00]，silie 加权最重） │ Focal(γ=2, α同上) + Dice + Lovász 三者按 1:1:1 组合（见 segformer_v2/losses.py） │
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 类别均衡手段   │ WeightedRandomSampler 按各类像素数加权采样                     │ 换成损失函数层面解决 + Copy-paste 增强（以 0.5 概率粘贴 silie 小目标裁剪块）     │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 训练轮数/batch │ 150 epochs，bs=24                                              │ 200 epochs，bs=16（640 分辨率更吃显存）                                          │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 断点续训       │ 无                                                             │ 支持 resume，每 epoch 存 ckpt 防丢进度                                           │       
   ├────────────────┼────────────────────────────────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────────────┤       
   │ 推理           │ stride 448                                                     │ stride 320（更密重叠）+ TTA（水平/垂直翻转）                                     │       
   └────────────────┴────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────────────────────────────────┘       
                                                                                                                                                                                
   可以看出 v2 的改进思路是针对 baseline 的短板——silie（撕裂）是小目标、类别极度不平衡——做的定向优化：更高输入分辨率 + 专门盯着前景的 Dice/Lovász 损失 + copy-paste 小目标增强 +
   推理端 TTA 和更密的滑窗。另外 v2 还多了按工况划分的 config_sw_s1~s4.yaml 系列配置，支持分场景（sw_s1~s4）训练评估。
